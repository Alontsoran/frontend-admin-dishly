# מדריך: קישורים אוטומטיים

## איך זה עובד?

המערכת מוסיפה קישורים אוטומטית לטקסט שאתה כותב ב-RichTextEditor.

### תהליך אוטומטי:

1. **כתיבה** - אתה כותב טקסט בעורך (RichTextEditor)
2. **המתנה** - המערכת מחכה 3 שניות אחרי שסיימת להקליד
3. **זיהוי** - המערכת מזהה מילות מפתח בטקסט
4. **התאמה** - המערכת מוצאת דפים רלוונטיים (לפי כותרת, keywords, description)
5. **הוספה** - המערכת מוסיפה קישורים אוטומטית לטקסט

### דוגמה:

**לפני:**
```
קבלן גבס בהרצליה מציע שירותי גבס מקצועיים
```

**אחרי (אוטומטי):**
```
<a href="/קבלן-גבס">קבלן גבס</a> בהרצליה מציע שירותי <a href="/גבס">גבס</a> מקצועיים
```

## איך להשתמש?

### שלב 1: פתח עורך דף
- לך ל-`/pages/new` או `/pages/:id/edit`
- פתח קומפוננטה עם שדה `richtext` (למשל: Text Block)

### שלב 2: כתוב טקסט
- כתוב טקסט רגיל בעורך
- לדוגמה: "קבלן גבס בהרצליה מציע שירותים מקצועיים"

### שלב 3: המתן
- **המתן 3 שניות** אחרי שסיימת להקליד
- הקישורים יתווספו אוטומטית!

### שלב 4: בדיקה
- פתח את הקונסול (F12) ותראה הודעות:
  - `✅ הוסף קישור אוטומטי: "קבלן גבס" → קבלן גבס`
  - `✅ נוספו X קישורים אוטומטיים`

## הגבלות

- **מקסימום 5 קישורים** אוטומטיים לטקסט
- רק **התאמות טובות** (לפי SEO scoring)
- לא מוסיף קישורים שכבר קיימים
- לא מוסיף קישורים בתוך קישורים קיימים

## בדיקה וטיפול בבעיות

### פקודת בדיקה בקונסול:
```javascript
debugAutoLinks()
```

פקודה זו תבדוק:
- ✅ האם ה-cache נטען
- ✅ האם ה-API עובד
- ✅ כמה דפים יש במערכת
- ✅ זיהוי מילות מפתח
- ✅ התאמות לדוגמה

### אם זה לא עובד:

1. **בדוק את הקונסול** - האם יש שגיאות?
2. **הרץ `debugAutoLinks()`** - מה זה מראה?
3. **בדוק Network tab** - האם ה-API נקרא?
4. **בדוק localStorage** - האם יש cache?

### איפוס cache:
```javascript
localStorage.removeItem('pages_autocomplete_cache')
localStorage.removeItem('pages_autocomplete_cache_timestamp')
```

ואז רענן את הדף.

## הערות

- הקישורים מתווספים **רק בעורך ויזואלי** (לא ב-HTML view)
- הקישורים מתווספים **אוטומטית** - אין צורך ללחוץ על כפתורים
- המערכת **לא שומרת** את הקישורים - הם נשמרים רק כשאתה שומר את הדף
